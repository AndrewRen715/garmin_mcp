# 攀岩日记技能

此技能帮助用户自动记录和更新攀岩训练日记。

## 功能

- 从 Garmin Connect 自动拉取最近的攀岩活动记录
- 按标准格式更新 `攀岩训练日记.md`
- 自动填充 Garmin 数据（时长、心率、消耗等）
- 智能识别缺失信息并询问用户补充
- 跟踪里程碑进度和训练统计

## 何时调用

当以下情况时调用此技能：
- 用户说"更新攀岩日记"
- 用户说"记录攀岩训练"
- 用户说"添加攀岩记录"
- 用户要求同步最新的攀岩活动到日记

## 使用流程

### 步骤 1：拉取 Garmin 数据

运行 `Scripts/get_climbing_activities.py` 获取最近的攀岩活动：

```python
# 关键输出字段
- 活动日期和时间
- 活动类型（抱石/难度/混合）
- 训练时长
- 平均心率 / 最大心率
- 卡路里消耗
- 活动地点（如果可用）
```

### 步骤 2：更新日记文件

根据获取的数据，按照以下格式更新 `攀岩训练日记.md`：

```
### YYYY-MM-DD (周X) - 地点

**🎯 训练类型**: 难度攀岩 / 抱石 / 混合训练\
**📊 Garmin**: X 分钟 | 平均 XX BPM | 最大 XXX BPM

#### ✅ 完成线路

| 难度  | 颜色   | 完成情况   | 备注     |
| --- | ---- | ------ | ------ |
| 5.9 | 橙色   | ✅ 完成    | 热身线路   |

#### ⚠️ 挑战中

| 难度    | 颜色   | 尝试次数 | 卡点位置      | 问题分析        |
| ----- | ---- | ---- | --------- | ----------- |
| 5.10a | 橙色   | 2 次  | 中间/最后5点   | 选路错误、手无力    |

#### 💡 总结

- **训练时长**: XX 分钟
- **技术进步**: 节奏控制和换脚意识明显提升
- **待改进**: 侧拉动作、选路能力
- **整体感受**: 状态良好
```

### 步骤 3：询问缺失信息

使用 `AskUserQuestion` 工具自动检测并收集用户的缺失信息：

1. **地点信息** - 攀岩馆名称（多选选项）
2. **完成线路** - 具体完成的线路难度（多选选项：5.9、5.10a、5.10b 等）
3. **挑战/突破** - 训练状态（多选：有突破、有挑战、保持状态、恢复训练）

## 数据格式规范

### 活动类型映射

| Garmin 活动类型 | 日记类型 |
| ----------- | ------ |
| `indoor_climbing` | 难度攀岩 |
| `rock_climbing` | 难度攀岩 |
| `bouldering` | 抱石 |
| 混合训练 | 抱石 + 难度 |

### 难度标识

- **难度攀岩**: 5.8, 5.9, 5.10a, 5.10b, 5.10c, 5.10d, 5.11...
- **抱石**: V0, V1, V2, V3, V4, V5...

### 颜色标识（参考）

| 颜色  | 常用难度范围 |
| --- | ------- |
| 绿色  | 5.8-5.9  |
| 橙色  | 5.9-5.10a |
| 黄色  | 5.10a-5.10b |
| 蓝色  | 5.10b-5.10c |
| 红色  | 5.10c+   |
| 紫色  | 抱石 V2-V3 |
| 黑色  | 抱石 V3+  |

## 输出格式

更新日记后，提供以下摘要：

1. **活动概览**: 日期、时长、心率、类型
2. **已更新内容**: 新增的训练记录位置
3. **缺失信息**: 需要用户补充的内容
4. **里程碑更新**: 是否达成新成就
5. **训练统计**: 总训练次数、累计时长等

## 实现细节

此技能利用以下脚本和文件：

- `Scripts/get_climbing_activities.py` - 获取 Garmin 攀岩活动
- `References/climbing_levels.md` - 当前水平和目标（可选）
- `攀岩训练日记.md` - 主日记文件

## 注意事项

- 优先使用已有的 `get_recent_climbing_activities.py` 脚本
- 自动过滤非攀岩相关活动
- 对于多条同日活动，合并记录
- 保持现有日记格式一致性
- 定期更新里程碑进度
